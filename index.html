Exam-day rules worth memorizing

stage 1
Get into any user account
stage 2
Elevate to the admin interface
stage 3
Read /home/carlos/secret
  • The victim visits the homepage every ~15 seconds and clicks email links — so exploit-server attacks land.
  • Any SSRF can reach an internal service on localhost:6566.
  • Never touch the _lab or _lab_analytics cookies — they run the exam itself.
  • Keep one Burp project file running the whole time; you must submit it afterward.
  • Stuck past 45 min on a stage? Switch to the other app and come back.
  • Don't delete your own account or a core component — it can make the exam unsolvable.
